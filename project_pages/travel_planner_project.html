Journey: Travel Planner

A web platform designed to streamline trip coordination and experience discovery for travelers. The application allows travelers to create, discover, rate, and organize custom itineraries using a secure, containerized architecture hosted on Google Cloud Run.

This website was built by a team of four, where I individually implemented the FastAPI REST backend, Cloudinary image service, and automated the Google Cloud deployment pipeline.

Key Features

  • Account Management: User registration, login/logout, profile updates, password changes, account deletion, and avatar uploads.
  • Travel Experiences: CRUD functionality for community travel posts featuring titles, descriptions, locations, keywords, and photos.
  • Search & Filter Experiences: Location and keyword filtering with server-side pagination, field sorting, and total match counting.
  • Community Ratings: Automated 1-5 star rating calculation with author self-rating protection and real-time average updates.
  • Collaborative Trip Planning: Itinerary creation with experience updates and multi-user sharing permissions.
  • Cloud Image Storage: Server validated file uploads offloaded to Cloudinary CDN to minimize database overhead.
